# Project instructions for Claude Code

## Git / GitHub

- **Always create a local commit after any change.** Every time you
  edit, add, or delete a file at the user's request, stage the
  relevant files and create a local commit describing the change.
  Do this without being asked — it's the default for this project.
  Follow the normal commit-message style (short "why" summary +
  `Co-Authored-By` trailer).
- **Never push to GitHub without explicit permission from the user.**
  `git push` (and any force-push, tag push, or `gh` command that
  publishes to the remote) requires the user to say so first — in
  this session. Local commits are automatic; pushing is a separate,
  explicit step that only happens on the user's word.
- This push rule applies to every remote and every branch, including
  `main`. No exceptions for "small" or "obvious" changes.
